Run

Scores every job on the dashboard against your resume, story bank, and stated industries/free-text preferences (src/ai.score_job) - role/title, location, remoteness, and salary are already hard-filtered before a job gets here, so this only judges what filtering can't. Test mode makes real LLM calls (not a fixture - it's meant to actually exercise the scorer), but always on the free default model regardless of what's picked above, and never updates the dashboard. Live mode uses the model you pick and updates the dashboard on success. "Pending jobs only" re-scores everything except jobs marked applied/rejected/irrelevant, leaving their existing scores untouched.
